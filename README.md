# Práctica Calculadora Gastos

**Página en vivo:** https://practicacalculadoragastos.onrender.com/
**Repositorio público:** https://github.com/JesusDun/PracticaCalculadoraGastos

## Objetivo del Proyecto

El objetivo principal de este proyecto es desarrollar una aplicación web funcional que permita a los usuarios registrar, calcular y gestionar sus gastos personales. El sistema facilita el control financiero mediante:

- **Registro de gastos:** Permitir a los usuarios agregar, editar y eliminar registros de gastos.
- **Cálculo automático:** Calcular totales, promedios y categorías de gastos.
- **Gestión de datos:** Almacenar y recuperar información de gastos en una base de datos.
- **Interfaz amigable:** Proporcionar una experiencia de usuario intuitiva y responsiva.

## Flujo de Trabajo Usado

El desarrollo se gestionó utilizando control de versiones con Git y GitHub bajo el siguiente flujo:

1. **Ramas de Desarrollo:**
   - **`main`:** Rama principal para código estable y de producción.
   - **`dev`:** Rama de desarrollo para integración de funcionalidades backend.
   - **`diseño`:** Rama dedicada para cambios en la interfaz de usuario y diseño frontend.

2. **Integración de Cambios:**
   - Los cambios de las ramas de desarrollo se integraban a `main` mediante *Pull Requests*.
   - Cada Pull Request requería revisión de al menos un integrante del equipo.

3. **Resolución de Conflictos:**
   - Antes de aprobar un Pull Request, otro integrante del equipo revisaba el código.
   - Durante la fusión, se resolvían conflictos de integración para asegurar que los cambios fueran compatibles.

4. **Historial de Cambios:**
   - Se mantuvo un historial limpio utilizando mensajes de *commits* claros y descriptivos.
   - Los mensajes de commit seguían el patrón: `[Acción] - Descripción del cambio`.
